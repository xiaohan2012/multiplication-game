# 乘法闪卡

A flashcard game for kids practicing the ×5 and ×10 times tables, with both factors at most 10.

Play: https://xiaohan2012.github.io/multiplication-game/

Each round draws 10 cards; type the answer and press Enter.
A missed card returns to the end of the round, and the result screen shows total time and the missed cards.

Everything lives in `index.html`, so opening it in a browser is enough to play offline.
